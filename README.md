# SoberAID

A simple sobriety day-counter with science-based recovery milestones.

## Status
Early development. Starting as a Python CLI, planned to grow into a web app.

## Planned features
- Track days sober from a user-set start date
- Show recovery milestones (sleep, mood, cognition) based on published timelines
- Log slips and restart cleanly without losing history

## Stack (planned)
- Python 3
- SQLite for storage
- Flask for a lightweight web version later

## Why
Built as a personal project to learn Python properly and support my own recovery.
